# 预注册偏离记录

## DEV-1（P2，QC 触发，2026-10-08）
- **现象**：QC2 未通过。速度版恒等式残差中位数 1.87%，99 分位 19.1%（阈值分别是 <1% 和 <5%）。
- **原因**：原始 trace 中的 velocity 以 bf16 存档。Δv = v_actual − v_clean 是两个大数相减，舍入误差相对小响应会被放大：
  - 按响应大小分五档，残差中位数从 7.1% 降到 0.57%；
  - 按条件看，匹配调暗 6.2%，暖材质 4.7%，相机条件 1.0–1.5%。
- **处理**：
  - P2 主分析改用 u_xt，即 f32 x_t 的逐步增量差（最后一步取 candidate actions）。按构造，它的恒等式残差为 0（实测 0.0）。
  - 速度版 u_vel 保留为敏感性对照。两版 c 的相关为 0.9992。
  - 判据、空间和层级都不改。
- **P1 的连带调整**：V_k 改由 u_xt 计算，V_k = ‖u_xt_k‖² / dt²。R_k 仍来自 bf16 存档的 readout RMS，这是只能接受的已知精度限制。
- **新增限制**：小响应条件下方向一致性 c 偏低，数值因素对此的贡献尚未分离。现有 BF16/FP32 对照只覆盖相机条件，光照、材质条件未验证。这条在结论中如实写明。
