## 1. 有效转化增益为何下降（第一部分，主分析）
- **数据与 QC**：8,673 个配对全部纳入，没有零分母。
  - 输出头身份通过：用头重算 clean 速度，相对误差中位 0.21%，最大 0.77%。
  - W₇ 数值秩 7，奇异值 0.64–0.75。
  - 带符号 Δr 算出的 R_k 与 P1 一致（中位差 0.03%）。
- **精确分解**：T_k = ρ_k · g_k · ν_k 逐配对成立（实现检查，最大残差 1×10⁻¹⁵）。从第 0 步到第 9 步：
  - Δln T = −1.754 [−1.800, −1.707]，即有效增益下降约 5.8 倍；
  - Δln ρ = −1.735；
  - Δln g = +0.001（区间含 0）；
  - Δln ν = −0.020。
- **稳定性**：
  - ρ 的份额按扰动族：相机 0.997、光照 0.976、材质 0.975。
  - 按锚点类：0.986–0.992。
  - 留一 suite：0.988–0.992。
  - 敏感性：配对等权 0.989；只用前三锚点 0.990；改用存档 BF16 速度 0.992。
- **下降是怎样形成的（描述性）**：
  - 读出差的能量在 10 步中增长约 16 倍，其中零空间能量增长约 19.5 倍。
  - 可读子空间内的能量在前 6 步（k = 0–5）几乎不变（+7% 以内），主要在最后 3 步上升，到第 9 步约为 2.9 倍。
  - 有效更新能量与可读能量的轨迹几乎重合（图 1d）。这也解释了 P2 中"最后一步占 20%"。
- **竞争解释 1：这是读出表示的一般几何性质。** 不支持。
  - clean 读出自身的可读比例只从 12.7% 降到 8.0%（1.6 倍）；扰动响应从 17.2% 降到 3.0%（5.7 倍）。
  - 第 0 步时，响应比 clean 读出更可读；第 9 步时则明显更不可读。
- **竞争解释 2：网络在后期时间步上，把同一个视觉差异表达到零空间。** 不支持（PH-3，事后，影子反事实，只有 τ0/5/9 三个点）。
  - 两条分支处在同一个 clean x_t 时，ρ 为 17.2% → 21.4% → 24.3%，不降反升，可读能量增长 14.6 倍。
  - 原生路径上同一时刻的 ρ 为 17.2% → 6.6% → 3.0%，可读能量只增长 2.9 倍。
  - 因此，下降只出现在两分支各走自己状态的原生路径上。这与 P2 的结果一致：原生速度差只有共享状态反事实的 0.53（τ5）和 0.41（τ9）。
  - 一个与数据相容的读法是：扰动分支自己的状态已经承载了一部分视觉效应，于是动作头能读到的剩余差异保持很小，而零空间差异继续累积。这一点是描述，不是因果识别。
- **反例与边界**：
  - 217/8,673 个配对（2.5%）的 ρ 没有下降，集中在小响应条件：匹配调暗 54、暖材质 48、冷材质 26、关头灯 24。
  - 在最小 10% 响应层中，ρ 的份额为 89.5%，ν 为 11.7%。
  - ν 不稳定（|Δln ν| > ln 2）的 28 个配对也集中在匹配调暗（12）和暖材质（13）。这些配对的线性参照偏差不可忽略，尚未进一步分离，不归因于 BF16。
- **对 P1/P2 的解释**：
  - P1 中 T_k 下降 7 倍，几乎全部是 ρ 下降；动作头本身的增益不变。
  - P1 的幅度律之所以成立，是因为读出总能量（以后期的零空间能量为主）与响应幅度同比例增长。它是幅度的代理量，不是动作读到的通道：只用第一步更新的幅度预测剩余更新幅度，R² 为 0.879；只用读出幅度为 0.835；两者合用为 0.879。
  - 没有训练或行为干预的证据，这一结构不提升为"保护机制"。

## 2. 带符号读出方向能否预测尚未发生的更新（第二部分，主分析）
- **设定**：截止点在第一次去噪更新之后，目标是其余 9 步累积的更新差（35 维）。按任务 5 折留出，同时做扰动族留出。
- **主要结果**（折外 EEF，合并）：

  | 模型 | EEF |
  |---|---|
  | 零 | 0 |
  | 条件 × 锚点均值 | 0.025 |
  | 幅度 | −0.397 |
  | **不拟合外推 9·u₀** | **0.677**（中位余弦 0.94；q0 上 0.921） |
  | β·u₀ | 0.675 |
  | 线性 u₀（M2L） | 0.636 |
  | + 带符号读出（M3） | 0.651 |
  | 只用读出（M3n） | 0.650 |
  | + 完整 Δr₀ 主成分 | 0.650 |

- **判定**：
  - M3 − M2L = +0.015 [0.013, 0.018]（条件均衡 +0.013），低于 0.02。
  - 扰动族留出：相机 −0.027 [−0.033, −0.022]、光照 0.000、材质 −0.006，0/3 为正。
  - **不满足"带符号读出提供额外知识"。**
  - 最强基线是不拟合外推 9·u₀，M3 比它低 −0.026 [−0.035, −0.018]。
- **事后 PH-1**：在 9·u₀ 之上再加读出零空间修正，增量为 −0.0007 [−0.0020, +0.0003]；扰动族留出三项都约等于 0。阴性结论稳健。
- **按条件**（描述性，无区间）：
  - M3 − M2L 在 8 个条件中落在 0.001 到 0.017 之间；相机 +15° 为 +0.028，+15° & 暖材质为 +0.021。
  - M3 − M2 在全部 10 个条件中为负（−0.007 到 −0.040）。
- **含义**：第 0 步读出的可读部分就是第一步更新本身（读出 only 的 M3n ≈ M3）；零空间部分对剩余更新没有可迁移的预测力。在本数据中，带符号方向是对已有动作信息的重述，不是额外知识。

## 3. 跨种子迁移（第三部分，次要分析）
- **q0（同一已访问状态，720 个单元，QC-S 全部通过）**：
  - 其他种子命令差的直接平均，EEF = 0.931，中位余弦 0.977。
  - 读出替代：0.900，C2 − C1 = −0.031 [−0.040, −0.023]。
  - 命令平均 + 读出：0.932，C3 − C1 = +0.0003。
  - 结论：两个判据都不满足。同一状态下，计划命令响应几乎与噪声种子无关；物理平移的 EEF 为 0.974。
- **后期锚点（不同已访问状态，不是同状态复现）**：
  - 直接平均失效：lm1 0.257，lm2 −0.077，later −0.120。
  - 按预注册规则字面判定：在 lm2 和 later 上，读出模型"迁移更好"（+0.20）。
  - 事后 PH-2 加入"拟合后的命令平均"后，lm2 和 later 上的优势降为 +0.006 和 +0.010，低于 0.02。也就是说，这部分优势主要来自标定和收缩，而不是方向信息。
  - 只有 lm1 上，读出替代仍比拟合命令平均高 +0.062 [0.030, 0.099]。这是事后线索，未经确认。

## 4. 相机 × 头灯：已有正交条件盘点
- D3 中没有相机 × 头灯的组合条件。
- 同仓已有一个因子设计：`native-write-flow-20261006-v1/context-direction-analysis-v1`，相机 C0/C15 × 头灯 Hbase/Hoff，36 个任务，静态锚点，两份记录噪声。
  - 在读出和当前 flow 上，"相机效应在头灯开与关之间"的方向余弦为 0.77–0.78；"头灯效应在两个相机角度之间"的方向余弦为 0.38–0.41。
  - 也就是说，关掉头灯后，相机效应的方向大体保持。这在生成层面不支持 P3 提出的"相机效应主要经由随相机移动的头灯"这一假设。
  - 但该分析没有测幅度和交互项 I，属于方向描述。
- **剩余缺口**：闭环后果的归因。最小方案是：在 D3 的 36 个任务 × 2 个初态 × 3 个种子上，做 2 × 2（相机 0°/+15° × 头灯原位/关闭）的闭环 rollout，复用 D3 的 trace 记录协议。这需要 GPU，不在本 Goal 的执行范围内。

## 5. 总判断与是否开启下一阶段
- **得到支持**：
  1. 有效转化增益沿去噪下降，几乎完全来自扰动响应的可读比例下降。动作头增益和数值偏差的作用可以忽略。
  2. 这种下降只在两分支各自状态上出现；在共享状态下，ρ 不降。
  3. 剩余更新的最佳预测是第一步更新的不拟合外推。
  4. 同一状态下，跨种子的命令响应几乎完全可以复现。
- **未获支持**：
  1. 带符号读出方向提供超出动作的、可迁移的未来更新信息。
  2. 读出方向在同状态下比命令平均迁移得更好。
  3. 相机效应主要来自头灯（在生成层面的方向证据不支持）。
- **对论文的意义**：第一阶段的"强幅度基线"现在有了机制层面的解释。读出总能量之所以能预测命令，是因为它与响应幅度同比例；真正被读取的是一个随去噪基本不变的低维可读分量，它与第一步更新等价。方向信息在这一关节上没有提供额外知识。
- **不自动开启 P5**。剩下的科学问题有三个：
  - 原生路径上零空间差异如何随状态分离而累积；
  - lm1 上的事后跨种子线索；
  - 闭环归因（需要 GPU）。
  - 前两项都不会改变第一篇论文的主张，第三项超出本 Goal 的范围。建议以本报告收束 P4。
