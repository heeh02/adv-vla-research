# P4 预注册：有效转化增益为何下降；带符号读出方向能否预测尚未发生的更新

冻结时间见 `PREREG-P4.sha256`。冻结早于任何 P4 新数值的计算。P1–P3 的预注册、结果和偏离记录保持不变，P3 未达到支持判据的结论不变。

## 0. 冻结前已知的信息（如实列出）
- **本数据（D3）**：P1/P2 的汇总已经看过。
  - 有效转化增益 T_k 的中位数从 0.087 降到 0.013。
  - 每步更新能量占比：前 8 步约 8–9.5%，最后一步约 20%。
  - c 的中位数为 0.92。
  - 读出变化能量 R_k 只来自 `readout_rms_by_dimension`，没有带符号的读出。
- **同仓库的其他数据**：
  - Fresh 数据（5 个条件，只有 τ0/τ5/τ9 三个时刻）上，有人做过可读比例：从约 20% 降到约 3%。
  - M4 分析（Fresh/D3 的 q0，init12→init13）：首步外推 10·δU₀ 在平移和旋转通道上明显优于同任务模板。
- **P4 尚未读过的数据**：D3 的带符号 `free/readout_delta`、`free/readout_clean`，以及输出头权重。
- **因此**：增益分解的方向（可读比例下降）在先验上是可预期的。P4 的贡献是：在 D3 的全部 10 步、10 个条件、多个锚点上，做精确的逐配对分解；并在公平信息条件下检验方向的预测价值。

## 1. 已核实的对象定义（来自源码，冻结前完成）
- **读出 r**：`PaliGemma.llm(..., method="trace_suffix")` 的输出，也就是动作专家经最终自适应归一化之后的表示。它正是 `action_out_proj` 的输入（pi0.py：`velocity = self.action_out_proj(readout[:, -action_horizon:])`）。
- **原生记录**：`free/readout_*`、`free/velocity_*` 是两条分支在各自原生状态上的原生记录值（`trace_pair_on_native_states`：own-path hidden/readout/velocity 是原生值）。
- **精度**：
  - Δr = r_actual − r_clean 在 BF16 中相减并存档（`summarize_pair`：诊断路径不把 BF16 升到 FP32）。
  - velocity 是 BF16 的头输出。
  - x_t 是 FP32，更新为 x_{k+1} = x_k + dt·v_k，dt = −0.1。
- **输出头**：`redacted-b0570e3a317b`（54,563 B，SHA 0f41a154…）。
  - 它与 D3 checkpoint 是否一致，由 QC-H 在数据上检验（见 §5），不靠文件名推定。
- **窗口**：前 5 个计划位置（p = 0..4）× 前 7 个动作输出维度（W₇ = kernel[:, 0:7]），与 P1/P2 的 E 空间一致。

  - pulse 与 clean 不进入分析。

- **锚点类**：q0 / lm1 / lm2 / later（slot ≥ 3）。

- **任务留出**：沿用 P1 的 5 折划分（seed 20261008，对排序后的 task_id 做置换，再按 k % 5 分折）。
- **内层调参**：在外层训练任务内部，按任务分 3 折（seed 20261009 + 外层折号）。
- **扰动族留出**：相机（6 个条件）/ 光照（2 个）/ 材质（2 个），每次留出一个族。

## 3. 第一部分：增益下降的精确分解（主分析 A）
对每个配对、每个去噪步 k，在 E 窗口内定义：
- R_k = Σ_p ‖Δr_{k,p}‖²：读出变化能量。
- 可读子空间：对 W₇（1024×7，从 BF16 精确转为 FP64）做 SVD，有效秩 r = #{σ_i > 10⁻³·σ₁}，U_r 是对应的左奇异向量。
  - 同时报告全部奇异值和熵有效秩（只作描述）。
- A_k = Σ_p ‖U_rᵀ Δr_{k,p}‖²：落在可读子空间内的能量。
- L_k = Σ_p ‖Δr_{k,p} W₇‖²：线性重算的输出能量。
- V_k = Σ_p ‖u_{k,p} / dt‖²：有效速度差的能量，与 P1 的 V_k 完全相同。
  - u_k 是 x_t 增量之差；第 9 步用候选动作端点。
- 由此得到精确恒等式：T_k = V_k / R_k = ρ_k · g_k · ν_k，其中
  - ρ_k = A_k / R_k：可读比例；
  - g_k = L_k / A_k：可读子空间内的输出增益；
  - ν_k = V_k / L_k：**线性参照偏差**。它在进一步分离之前不归因于 BF16 噪声，原因可能包括 Δr 的 BF16 相减舍入、各分支头输出的 BF16 舍入、矩阵乘法的累积方式等。
- **逐配对首末对数变化**：Δlog X = log X₉ − log X₀，对 X ∈ {T, ρ, g, ν} 各算一次。恒等式 Δlog T = Δlog ρ + Δlog g + Δlog ν 逐配对成立；这只作为实现检查，不算发现。
- **聚合（主）**：先在每个（任务 × 条件）格内对配对取平均，再在每个条件内对任务等权平均，最后对 10 个条件等权平均。均值是线性的，所以三项可以精确相加。
  - 各项的"份额"等于该项的聚合值除以 Δlog T 的聚合值。
  - 不把各项的中位数相加当作归因。
- **敏感性**：
  1. 配对等权的合并平均；
  2. 只用 slot ≤ 2；
  3. 速度改用存档的 `native/*/velocity` 之差（BF16），不用 x_t 增量。
- **分层报告**：按条件、按扰动族、按锚点类、按 suite，并给出全部 10 步的剖面（log X_k 的聚合均值）。
- **判定规则**：
  - 某一项可称为"下降的主要来源"，需要同时满足：
    - 份额 ≥ 0.5；
    - 区间不含 0；
    - 在 ≥ 8/10 个条件中与总体同号。
  - 若 |ν 的份额| < 0.1，且区间上界 < 0.2，则称"下降不能归于线性参照偏差"。
  - 否则如实报告 ν 不可忽略，并列出它集中在哪些条件。
- **零分母与特殊案例**：
  - 若 k ∈ {0, 9} 时 R、A、L、V 中任一为 0 或非有限，该配对不进入分解；按条件和原因计数。
  - 小响应层：V₀ 位于全体最低 10% 的配对，单独报告其分解。
  - 不稳定案例：|Δlog ν| > ln 2，计数后做"剔除它们"的敏感性分析。主分析保留它们。
  - 反例：Δlog ρ ≥ 0 的配对（可读比例没有下降），按条件计数并报告。
- **描述性的竞争解释检查（不作判据）**：
  - clean 读出本身的可读比例 ρ^clean_k = Σ_p‖U_rᵀ r_clean‖² / Σ_p‖r_clean‖² 是否也随 k 下降。若是，可读比例下降是表示轨迹的一般性质，而不是扰动特有的。
  - 可读能量 A_k 与零空间能量 R_k − A_k 各自的剖面。

## 4. 第二部分：早期信息预测剩余更新（主分析 B）
- **截止点**：第一次去噪更新完成之后。
  - 目标：Y = Σ_{k=1..9} u_k（35 维，E 窗口），即其余 9 步累积形成的更新差。
  - 已观察部分是 u₀。最终计划命令差 D = u₀ + Y 单独报告，并始终区分已观察与未来。
- **允许的输入**：
  - 条件和锚点类标签；
  - u₀（35 维）；
  - Δr₀（第 0 步、p = 0..4，共 5×1024），拆成可读坐标 a₀ = U_rᵀΔr₀（35 维）和零空间部分 n₀ = Δr₀ − U_r U_rᵀ Δr₀（5,120 维）；
  - R₀ = Σ‖Δr₀‖²。
- **禁止的输入**：k ≥ 1 的任何读出、速度、状态或累积量，以及最终动作；clean 读出本身；目标任务的任何统计量。
- **模型**：所有拟合、标准化、PCA 和超参选择都只在训练部分完成。
  - Z：Ŷ = 0（参照，EEF = 0）。
  - M0（强均值基线）：训练任务中同（条件 × 锚点类）格内 Y 的均值；格内少于 20 个时退回条件均值。
  - M1（幅度基线）：Ŷ = ŝ·ê。
    - ê 是 M0 格均值的单位方向。
    - ŝ = exp(ĥ/2)，ĥ 由训练集 OLS 预测 log‖Y‖²，自变量为 [log R₀，条件哑变量，锚点类哑变量]。
  - M2（简单外推，不拟合）：Ŷ = 9·u₀，即恒定流的保持方向与增益。
  - M2g（增益外推）：Ŷ = β_c·u₀，β_c 是训练集中每个条件的最小二乘标量。
  - M2L（线性动作基线）：Ŷ = M0 + B·z(u₀)。
    - 用岭回归拟合残差 Y − M0，z 为训练集标准化。
    - λ 在 24 个值 logspace(−3, 4) 中，由内层 CV 选择。
  - M3（带符号读出）：Ŷ = M0 + 岭回归[z(u₀), z(a₀), PCA_m(n₀)]。
    - PCA 在训练集上用随机 SVD（seed 20261009，过采样 16，4 次幂迭代），先中心化。
    - 超参共 24 个组合：λ ∈ logspace(−2, 3) 取 6 个值，m ∈ {8, 16, 32, 64}，由内层 CV 选择。
    - 这样 M3 与 M2L 的调参预算相同。
  - 描述性模型：
    - M3n = M0 + 岭回归[z(a₀), PCA_m(n₀)]（不含 u₀）；
    - M3f = M0 + 岭回归[z(u₀), PCA_m(未拆分的 Δr₀)]。
  - 内层 CV 的选择准则：内层验证的合并 EEF 最大。
- **指标**：
  - 主指标是合并的解释能量比例 EEF = 1 − Σ‖Y − Ŷ‖² / Σ‖Y‖²，取外层折外预测。
  - 次要指标：
    - 条件均衡 EEF（每个条件内的 EEF 取等权平均）；
    - 中位余弦 cos(Ŷ, Y)（任一范数为 0 时记为未定义，不填值）；
    - 预测 log‖Y‖² 的 R²：只比较 [log R₀] / [log‖u₀‖²] / 两者都用，均加上格哑变量。
  - 区间：固定折外预测，对任务做 bootstrap，计算差值区间。
- **扰动族留出**：在两个族上训练，在第三个族上测试。
  - 未见族没有条件标签可用，所以所有模型去掉条件项：M0 改为同锚点类的合并训练均值，M2g 改为合并的 β。
  - 超参在训练族内部按任务做 CV 选择。
- **判定规则（主对比：M3 − M2L，任务留出）**：
  - "带符号读出提供了关于未来更新的额外知识"，需要同时满足：
    - ΔEEF ≥ 0.02；
    - 区间下界 > 0；
    - 三个扰动族留出中至少两个 ΔEEF > 0。
  - 否则判"增量很小或不稳定"，P4 以强幅度和动作基线及其边界收束。
  - 同时报告 M3 相对每个基线的差值，以及哪个基线最强。
- **失败条件报告**：按条件、锚点类、扰动族，分别列出 M3 不优于 M2L 的情形，以及 M2（9u₀）误差最大的情形。

## 5. 第三部分：跨种子迁移（次要分析 C）
- **单元**：q0 上同一 root × 条件、3 个种子都有记录的单元，预期 720 个单元、2,160 个目标。
- **QC-S（同态核验）**：
  - 同一 root × 条件在 q0 的三个种子之间，`free/visual_token_rms` 应逐位相同，说明扰动和观测完全相同。
  - `free/readout_clean` 第 0 步应不同，说明噪声不同。
  - 报告两者成立的比例；不成立的单元剔除并计数。
- **目标**：种子 i 的计划命令差 D_i = Σ_k u_k（35 维，模型空间）。物理平移（dphys 前 5 步之和，3 维）作为次要指标。
- **预测量**：只来自其他种子 j ≠ i，目标种子的任何生成信息都不进入输入。
  - C1（直接平均，不拟合）：Ŷ = mean_j D_j。这是强对照，信息条件为"其他种子的完整生成输出"。
  - C0（幅度基线）：Ŷ = ê_cond × mean_j ‖D_j‖，ê_cond 是训练任务中该条件 D 均值的单位方向。
  - C2（读出方向替代命令）：Ŷ = M0_cond + 岭回归[z(ā), PCA_m(n̄)]。
    - r̄^{(j)} 是其他种子 10 步 Δr 的时间平均（5×1024）；ā、n̄ 是它的可读坐标与零空间部分，再对 j 取平均。
    - 信息条件与 C1 相同，都是其他种子的完整生成。
  - C3（命令平均 + 读出修正）：Ŷ = C1 + 岭回归[PCA_m(n̄)]，拟合残差 D_i − C1。
  - 调参预算与 §4 相同，按任务做 5 折外层、3 折内层。
- **判定规则**：
  - ΔEEF(C2 − C1) ≥ 0.02 且区间下界 > 0，才称"读出方向比直接命令平均迁移得更好"。
  - ΔEEF(C3 − C1) 满足同一阈值，才称"读出在命令平均之外有增量"。
  - 否则明确报告不优于直接命令平均，不再更换特征。
- **后期锚点**（lm1 / lm2 / later）：各种子的已访问状态不同，单独报告，不称作"同状态下的跨噪声复现"。

## 6. QC（先于结果）
- **QC-H（输出头身份）**：在全部配对的第 0 步和第 9 步，用 clean 读出重算 v̂_clean = r_clean·W + b（FP32），与存档的 `native/clean/velocity` 比较，看 E 窗口内的相对误差。
  - 中位数 < 1% 且 99 分位 < 5% 才通过。
  - 不通过时停止第一部分，并报告缺口。第二、三部分不依赖 W，但其中的可读坐标依赖 W，同样暂停。
- **QC-X**：两条分支的 x₀ 逐位相等；u_k 的累加与候选动作差闭合（实现检查）。
- **QC-N**：全部数组有限；BF16 解码正确（与 P1 的 `readout_rms_by_dimension` 重算比较：由 Δr 算出的 R_k，与 P1 的 R_k 中位相对差 < 1%）。
- **QC-S**：见 §5。

## 7. 信息边界与资源
- 原始数组和权重只在百度 CPU 作业中读取（JD OSS 预签名 URL 按字节范围读取；BOS 用作用域受限的 STS）。
- 返回 Mac 的只有逐配对标量表、模型指标、QC 和图表输入。凭据只在内存和作业环境中。
- 资源：GPU 为 0；不做新的模型前向、rollout 或训练。

## 8. 结论边界
- 本分析描述的是同一状态下局部生成敏感性的内部结构，不涉及任务成功或伤害。
- 增益分解即使给出稳定结构，没有训练或行为干预证据时，也不称为保护机制。
- 带符号方向的结论只适用于本数据的任务、条件和截止点。
