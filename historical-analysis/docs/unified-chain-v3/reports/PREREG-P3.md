# P3 预注册：从命令变化到任务后果（冻结于 2026-10-08，计算 P3 之前，且未查看 P1/P2 结果）

## 问题
命令变化的幅度相近时，以下三点能否解释后面的落点和结局：
- 命令变化的**方向**（是否系统性地指向某一侧）；
- **发生阶段**（第一次查询 q0、landmark1、landmark2）；
- **持续性**（跨噪声种子是否一致）。

关键在于，要说明前面的响应如何导致后面的约束违例。不能用终态违例去"解释"终态失败。

## 数据（全部为 D3 原件）
- **同状态平移命令变化**（局部视觉敏感性，clean@visited）：P2 的 dphys，形状 (10,7)，物理动作空间。
  - 取前 5 个执行步的平移维 0..2 求和，记为 d_q（3 维），q ∈ {q0, lm1, lm2}。
- **末端（EEF）轨迹**：机器人侧 `trajectories/qNNN-state.npz`（来自既有的 36-shard 提取包）。
  - 扰动 episode 与 clean 伙伴 episode 在相同控制步上的末端位置差。这部分包含轨迹分叉，单独标注为"闭环偏差"。
- **物体落点**：在最后一次记录的查询时刻，相对 clean 成功参考的 (dx, dy)。
  - 物体由启发式检测得到，覆盖 23 个任务。
  - 不是终态，此限制必须在结论中写明。
- **结局**：原始 result.json，以及 clean 伙伴（同 root、同 noise）。

## 定义
- **单元**：root × 条件，共 46 个 root × 10 个持续条件。所谓"系统性分量"，指单元内对 3 个噪声种子取平均。
  - D_sys = 各种子 Σ_q d_q 的平均，投影到水平面 (x, y)。
  - O_sys = 成功 episode 的 (dx, dy) 平均。需要至少 2 个成功种子。
  - E_sys = landmark2 之后第一个记录查询时的末端位置差平均，取 (x, y)。
- **坐标**：动作平移轴与世界 x/y 轴的对齐方式，先从数据核对：clean 执行动作与末端位移之间的回归斜率符号。若轴未对齐，先求一个固定的线性映射，再做比较。这一步只是 QC，不是判据。

## QC
- QC-P3a：clean episode 中，相邻查询的末端位移与执行平移动作之和的方向余弦，中位数 > 0.8。用于确认动作轴的含义。
- QC-P3b：每个单元的成功种子数，以及单元数量。

## 主分析与判据（冻结）
- **P3-D1 方向链**：只在相机条件（6 个）中，且 ‖O_sys‖ 高于重采样噪声底（外推版 10.6 mm；以单元为单位，比较 O_sys 与"clean 重采样单元"分布的 95 分位）的单元上，计算 cos(D_sys, O_sys)。
  - 若中位余弦 > 0，且任务簇 bootstrap（2000 次）95% 区间下界 > 0，判定"命令偏差的方向预测落点偏移的方向"。
  - 同时报告 cos(D_sys, E_sys) 与 cos(E_sys, O_sys)，构成一条链。
- **P3-D2 镜像检验**：同一 root 下，计算 cos(D_sys(+θ), D_sys(−θ))，θ = 15° 与 30°。
  - 几何镜像假设预期 < 0；与方向无关的默认偏移预期 > 0。
  - 报告中位数与 bootstrap 区间。判据：区间不含 0 时，按符号下结论。
- **P3-D3 结局**（次要；事件少，功效低）：在 clean 成功配对中，比较两类预测量对"损害"的预测：
  - 单元层的系统命令幅度 ‖D_sys‖；
  - 系统落点偏移 ‖O_sys‖，用留一种子估计，避免同种子泄漏。

  做法：先在条件内排序，再算 AUROC。报告值和区间，并附上可靠性上限（分半）。不设通过阈值，只报告；不据此下机制结论。

## 只描述、不作判据
- 阶段：分别用 d_q0、d_lm1、d_lm2 代替 Σ_q，比较各自与 O_sys 的余弦。
- 光照与材质条件的同类余弦（预期接近底噪）。
- pulse 条件：D_sys 只含 q0 一项时，与 O_sys 的关系。

## 结论边界
- 落点不是终态。
- 物体识别是启发式的。
- 只覆盖 23 个任务。
- 在 root × 条件层面成立的结论，不外推到单个 episode。
