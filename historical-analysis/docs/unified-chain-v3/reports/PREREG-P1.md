# P1 预注册：读出变化转化成动作变化（冻结于 2026-10-08，P1 数据计算之前）

## 问题
读出层（最终归一化后的表示）变化幅度相近时，转化增益（方向与头增益的综合）和跨步累积，能否解释执行命令变化中幅度解释不了的差异？这种解释在留出任务后是否依然成立？

## 数据
- 人群和配对单位与 P2 相同：D3 原始 trace，10 个持续条件，每个配对 = (episode, 查询)。
- 新读取的成员：`free/readout_rms_by_dimension`，形状 (10, 2, 1024)，bf16。
  - 含义（`paired_trace.py`）：前 5 个动作位置上，读出差异按维度计算的 RMS。属于原生记录。
  - 由此得到 R_k = 5 · Σ_d rms²_{k,d}，即第 k 步前 5 个位置读出差异的能量。
- P2 已有的量：u_vel、dphys（物理动作差异）。

## 定义（E 空间 = 前 5 个位置 × 维度 0..6）
- 第 k 步速度差能量：V_k = ‖Δv_k‖²_E；转化增益 T_k = V_k / R_k。
- 读出总能量 Rtot = Σ_k R_k；有效转化增益 T_eff = Σ_k T_k R_k / Rtot。
- 恒等式：S = Σ_k dt_k² V_k = 0.01 · Rtot · T_eff（dt 恒为 −0.1）。
- 与 P2 合并：F = S · K_eff · c²。
- 执行命令能量 P = ‖Δphys_E‖²，adapter 因子 α = P / F。
- 完整链条：log P = log(0.01) + log Rtot + log T_eff + log K_eff + 2 log c + log α，各项精确相加。
- 只有读出及其之后的环节适用这条链。L1、L9 不能用动作头去映射，本分析不涉及。

## QC
- QC-a：用 R_k 与 V_k 重算 S，与 P2 的 S 的相对差异中位数 < 1%（来源同为 bf16 速度）。
- QC-b：恒等式 P = F·α 按定义成立；报告 α 的分布。α 应主要取决于各维度的归一化尺度。

## 主分析与判据（冻结）
- **P1-D1 方向/增益是独立因子**：对 log S 做两因子分解（log Rtot、log T_eff），沿用 P2 的分层投影：条件、任务、条件×任务、格内。若某层级满足以下两条，则判定为独立因子：
  - Var(log T_eff) / [Var(log Rtot) + Var(log T_eff)] ≥ 0.25；
  - 4 折留一 suite 时，该比例变化不超过 ±0.10。
- **P1-D2 可迁移的预测增量**：以任务分组做 5 折交叉验证，目标是 log P，比较三个模型的折外 R²：
  - A：只用 log Rtot（只看幅度）；
  - B：A + 训练折估计的条件层平均 log T_eff、平均 2 log c、平均 log K_eff（条件的方向与累积档案）；
  - C：A + 条件哑变量（上限参照）。

  当 B − A ≥ 0.05，且任务簇 bootstrap（1000 次）的 95% 区间不含 0 时，判定"方向与累积信息可迁移到留出任务"。
- **P1-D3 迁移到留出扰动族**（G2 雏形）：族的划分为相机（6 个条件）、光照（2 个）、材质（2 个）。留出一个族后，用其余族的条件档案外推。只报告折外 R²，不设阈值，只作描述。

## 只描述、不作判据
- T_k 在 10 个去噪步上的剖面；
- T_eff 与条件、查询位置的关系；
- 与 Fresh 已测可读比例的定性对照。
