# 统一链条第一阶段结果：P2 / P1 / P3（修订版 v2.1，2026-10-09）

本版按 2026-10-09 的两轮外部审阅修订（v2 对应第一轮，v2.1 对应第二轮）。审阅提到的数值我都在本地独立复算过，全部一致。修订内容见文末"修订记录"。首轮版本保存在 `REPORT-P1P2P3-v1.md`、`v1/` 和 `../figures-v1/`。

## 一句话总结
在所分析的 D3 任务与持续扰动中，总读出能量能较好地预测**同一次生成**的计划命令能量（留出任务 R² = 0.84）。各去噪步的更新大体同向累积，但最后一步贡献最大，且部分样本存在明显抵消。在幅度之外，条件平均的转化与累积档案只带来很小的额外预测收益。命令偏差方向与落点偏移方向的关联，在预注册定义下没有达到支持判据：点估计为正，但区间很宽。这撤回的是首轮的确认性主张，并不证明方向链不存在，目前只能作为探索性证据。这些结果刻画的是局部生成敏感性；它们与闭环任务后果的联系，还需要独立的时间、执行和任务几何证据。

## 数据与流程
- 数据：D3 原始 trace，共 36 个 shard、11,420 个锚点 trace、3,024 个 episode。只按字节范围读取所需的小成员，零错误。
- 字段来源：
  - x_t、velocity、readout：原生记录。
  - shared_xt：反事实。
  - clean：同一已访问状态上换回 clean 渲染（clean@visited），不是独立的闭环轨迹。
- **"命令"的含义**：同一已访问状态下，adapter 输出的前 5 步物理动作之差，即**计划命令前缀**，不是实际下发的执行记录。clean 分支的动作从未被执行过。
- 主分析人群：10 个持续条件，共 8,673 个配对（episode × 锚点）。
- 预注册在计算前冻结，哈希可以核对。这只能证明本地冻结记录前后一致，不能独立证明冻结前没有看过相关数据。
- 偏离记录：`DEVIATIONS.md` 中的 DEV-1 至 DEV-6。

## 1. 读出 → 计划命令：一个强的幅度基线（F1、F3）

```
计划命令能量 = 0.01 × 读出变化能量 × 有效转化增益 × 有效步数 × 一致性² × adapter 因子
```

这是逐项精确相加（取对数后）的恒等分解。重构残差为 0 是定义决定的，不是独立验证。

- **条件之间**：读出能量相差约 35 倍（匹配调暗 4.1，−30° 为 142.5）。其余四个因子的**条件中位数**很接近：
  - 转化增益 0.022–0.026
  - 有效步数 9.4–9.8
  - 一致性 0.80–0.95
  - adapter 0.35–0.46
- **单个配对之间并不固定**：转化增益的 5–95 分位是 0.0105–0.0622，相差约 6 倍。所以只能说"条件中心稳定"，不能说"每个样本都用固定增益"。
- **预测检验（F3）**：
  - 只用总读出能量，在留出任务上预测计划命令能量，R² = 0.836；留出整个扰动族时 R² 为 0.74–0.79。
  - 再加入"条件平均档案"（训练折中各条件的平均转化增益、一致性、有效步数），即模型 B，R² 增加 0.0016 [0.0002, 0.0030]。增益很小，但区间不含 0。
  - 留出扰动族时用的是 B′，不是 B：留出族的条件在训练中没有出现，它们的档案无法直接估计，于是用"训练条件的平均 log 读出能量 → 档案"的回归来外推。外推的输入是留出条件自己的平均 log 读出能量，属于测试输入，但不含标签；全程没有用到测试样本的命令能量。
- **这个检验覆盖不到的地方**：
  - B 模型加的是三个条件均值标量，不是逐样本、带符号的读出方向。所以本结果不能写成"方向信息没有用"或"方向无法迁移"。逐样本方向检验需要 `readout_delta`，约 200 KB/trace、合计约 2.3 GB，按规定应在百度云上计算。
  - 读出能量汇总了全部 10 个去噪步，所以这是**同一次生成内部关系**的跨任务预测，不是提前预测未来动作或失败的在线指标。
- **含义**：在本数据范围内，读出变化总能量是计划命令能量的强基线。条件之间的差异在读出能量上已经明显可见，例如关头灯与匹配调暗相差约 9 倍（37.7 vs 4.1）。
  - 这些差异在哪一层形成、各层各占多少，尚未定位。
  - 后期锚点的已访问状态会因闭环而随条件不同，所以读出能量的条件差异中，可能有一部分来自状态差异，不能全部归给上游视觉处理。

## 2. 去噪过程：较强的同向累积，最后一步贡献最大（F2）

- **更新分布在多个去噪步上，但后期更重。** 每步能量占比的中位数：
  - 前 8 步为 8.0–9.5%；
  - 倒数第二步 11.4%；
  - 最后一步 20.4%，四分位范围 14.9–27.8%。

  首轮报告说"基本均匀、最后两步略高"，与数据不符；当时 F2 的纵轴把最后一步截掉了。
- **整体同向，但存在抵消。**
  - 一致性 c 的中位数为 0.92，没有达到预设的"系统性抵消"判据。
  - 但有 40.4% 的配对 c < 0.9，11.5% 的配对 c < 0.7。
  - 按条件看，c < 0.9 的比例为：相机 24–30%，关头灯 40%，材质 61–67%，匹配调暗 80%。
  - 准确的说法是：整体较一致，但较强的抵消出现在部分样本和条件中，尤其是小响应条件。数值因素对小响应条件低一致性的贡献尚未分离；光照和材质条件没有做过 FP32 对照。
- **"方差份额 2%"不等于"累积只贡献 2%"。** 2% 是预注册定义的方差比，没有计入协方差。
  - 在条件层，log F 的方差中，除 log S 以外的部分（含协方差）约占 25%，主要来自 cov(log S, log c²)：响应越大的条件，一致性越高。
  - 拆开来看（A = log K_eff + 2 log c）：Var(A) / Var(log F) 只有 1.95%，2 Cov(log S, A) / Var(log F) 为 23.51%，合计 25.46%。
  - 所以这 25% 是恒等式中的剩余方差加协方差项，主要反映幅度与累积项的共同变化。不能说成"累积独立解释了 25%"，也不能说成"累积贡献了 25% 的行为影响"。
  - 速度版对应为 1.75% 与 22.44%。
- **有效转化增益沿去噪步下降约 7 倍**（0.087 → 0.013）。这只说明：单位读出能量对应的速度能量在下降。它本身不能区分以下三种可能：
  1. 读出变化进入动作头的零空间；
  2. 在动作头可读的空间内，转向增益较低的方向；
  3. 数值实现的影响。

  首轮写的"转向不可读方向"说得过强。可读比例、头内增益和数值项的分解，目前尚未完成。
- **测量对象**：主分析用的是 x_t 的实际更新增量（有效更新），不是动作头原始输出的速度（DEV-1）。速度版重跑后所有判定不变，见 `P2-RESULTS-u_vel.json` 和 `P1-RESULTS-u_vel.json`。
- **反事实对照**（影子数据，只作解释）：在相同时刻，自然路径的速度差是共享状态反事实的 0.53（τ5）和 0.41（τ9）。

## 3. 计划命令 → 任务：只有探索性证据（F4）

- **D1 方向链（主分析未达到支持判据）。** 相机条件中，落点偏移高于底噪（29.8 mm）的单元共 33 个，来自 14 个 root、9 个任务。
  - 主分析（预注册三锚点）：0.42 [−0.16, 0.74]。
  - 敏感性一（全锚点，即首轮做法）：0.53 [0.23, 0.89]。
  - 敏感性二（10.6 mm 底噪）：0.28 [0.06, 0.46]，175 个单元，23 个任务。
  - 三种定义下点估计都为正，但只有非主分析的定义区间不含 0。结论是"未获支持"，不是"方向链不存在"。
  - **人群限制**：O_sys 只用成功种子估计（至少 2 个），再筛掉低于底噪的单元。所以这是在"选出的成功 episode"中的方向关联，不能用来解释失败。
  - 落点取的是最后一次查询时的位置，不是终态。
- **中间环节对不上。** 第二个锚点之后的末端偏差，与命令方向的余弦约为 0（−0.004 [−0.85, 0.10]），与落点方向的余弦为 0.12 [−0.29, 0.64]。
- **分阶段（描述性）**：q0 为 0.25，lm1 为 0.25，lm2 为 −0.37 [−0.74, −0.08]。后期的局部命令偏差与最终偏移方向相反。
- **D2 左右转同向（稳健）。** 46 个预注册 root 和全部 72 个 root、三锚点和全锚点四种组合下，都判为同向。
  - 这排除了简单的奇对称（镜像）响应。
  - 但它**不能排除几何解释**：有限角度下的非线性、遮挡、偶对称响应，同样可以产生同向变化。
- **D3 结局（次要，功效低，不设阈值）**：

  | 人群 | ‖D_sys‖ AUROC | O_loo AUROC |
  |---|---|---|
  | 共同人群（1,313 条，61 次损害，23 个任务） | 0.46 [0.39, 0.57] | 0.60 [0.40, 0.72] |
  | ‖D_sys‖ 自身人群（2,050 条，100 次损害，35 个任务） | 0.36 [0.30, 0.48] | — |

  - 在共同人群上，两者的区间都包含 0.5。
  - 自身人群中 ‖D_sys‖ 的 AUROC 低于 0.5，意思是：同一条件内，系统性命令偏差越大的单元，反而越少受损。原因不明，可能是任务之间的混杂。这一点不作解释。
  - **两者之差（事后核查，非预注册）**：在共同人群上做成对任务 bootstrap（10,000 次，同一次抽样同时计算各个 AUROC），O_loo − ‖D_sys‖ = +0.140 [−0.147, +0.299]。所以没有稳定证据表明落点摘要优于命令摘要。见 `P3-POSTHOC-auroc-paired.json`。
  - **信息条件不一致**：‖D_sys‖ 包含被评价种子自身的信息，而 O_loo 排除了该种子。事后补了留一种子的命令幅度 D_loo：AUROC 0.45 [0.39, 0.54]；O_loo − D_loo = +0.152 [−0.120, +0.303]。结论不变。这些数值只能算事后关联；要称为跨种子预测，需要事先统一信息条件。
  - **信度**：能直接报告的只有单种子幅度的平均跨种子秩相关，命令为 0.739，落点为 0.461。它不是实际预测量（‖Σᵢ Dᵢ / n‖ 与 O_loo）的信度，也不是预测上限。原因有两点：向量先平均会发生抵消，两种统计量之比的 95 分位约为 1.61；落点还涉及成功筛选、共享 clean 参照和可用种子数不固定。v2 中由此外推的 0.89 和 0.63 已撤回。
- **没有完成的部分**：预注册问题中的"命令幅度相近时"，没有在判据里操作化，也没有实际做幅度匹配。pulse 条件在 D3 中没有 q0 trace，无法分析。

## 4. 头灯与相机的共同方向（描述性，不是归因）
- 同一场景内（三锚点，72 个 root），关头灯与四个相机条件的命令偏差方向余弦为 0.72–0.83。
- 对比：匹配调暗与关头灯 0.07，暖材质与 +30° 为 −0.19。
- 各条件的全局合成长度为：相机 0.30–0.38，关头灯 0.29，匹配调暗 0.12，材质 0.11–0.16。所以这个共同方向是按场景成立的，不是一个全局统一的方向。
- **方向相近不能完成归因。** 它不能说明相机效应主要来自头灯。要检验，需要"头灯关闭时转动相机"或"相机转动、头灯固定"这类可分离的输入条件。D3 中没有这样的条件，需要新的 rollout；GPU 使用尚未授权，所以没有做。

## 5. 对中心假说的判定（修订）
- **读出 → 计划命令**：条件之间存在强的幅度基线，条件平均档案只有很小的增量。逐样本的方向作用尚未检验。
- **去噪累积**：整体较强同向，最后一步贡献最大，部分样本和条件中存在抵消。
- **计划命令 → 任务**：方向关联在预注册定义下没有达到支持判据（点估计为正，区间宽，不是反证）。左右转同向这一发现是稳健的，但它不能区分几何与光照两种来源。
- 第一阶段能支撑的论文内容是"生成过程"部分：一个强基线及其适用范围，而不是一条已被证明的通用幅度律。

## 下一步（按第二轮审阅的顺序）
1. **现有小表和定义的修订**：v2.1 已完成。P3 未获支持的主结论保持不变。
2. **增益分解与方向检验合并为一个边界明确的 CPU 分析（P4，待批准后再写预注册）。**
   - **前提**：读出就是 `action_out_proj` 的输入（pi0.py:363）。动作头是单层线性映射，所以 Δv_k = W·Δr_k，偏置相互抵消。因此 E 空间（前 5 个位置 × 维度 0..6）中，"可读子空间"就是 W 前 7 行张成的 7 维子空间。
   - **增益分解（精确恒等式）**：T_k = ρ_k · g_k · ν_k，其中
     - ρ_k 是读出变化落在可读子空间里的比例；
     - g_k 是可读子空间内的增益，‖W_E Δr_k‖² / ‖P Δr_k‖²；
     - ν_k 是数值项，有效更新与线性重算之比，‖Δv_eff,k‖² / ‖W_E Δr_k‖²。
     - 要回答的是：T_k 下降 7 倍，主要来自零空间、可读空间内的低增益方向，还是数值项。
   - **方向检验，先固定信息截止点**：用全部 10 步带符号的读出，经已知的 W 和积分，几乎可以直接重建计划动作，这样的"预测提升"只是计算关系的重述。所以特征只能取截止点之前的信息（例如只用早期若干步，或跨种子、跨锚点），并在相同截止点上设置只看幅度的对照，同时固定留出划分。
   - **需要的资源**：`readout_delta` 约 2.3 GB，以及 checkpoint 中 W（1024×32）。按规定在百度云上做 CPU 计算，只回传摘要。
3. **是否需要新增相机 × 头灯 rollout**：先盘点现有记录中的正交条件（例如 D3 已有相机 × 材质组合）能回答哪些生成层问题。只有闭环归因仍缺少不可替代的证据时，才申请 GPU 采集。
4. **读出之前的环节**：视觉 token 的入口变化、注意力质量、注意力写入的 RMS，所需成员都很小。注意控制已访问状态的差异。

| AUROC 比较 | 两个独立区间 | 增加成对 bootstrap 差值和 D_loo，标为事后核查 | 两个独立区间无法判断差值 |
| 25% | "除 S 以外约占 25%" | 拆成 1.95%（Var A）+ 23.51%（2 Cov） | 不是独立解释率 |
| 读出之前 | "大部分在读出之前已形成" | "在读出能量上已明显可见"，来源层未定位，可能混有状态差异 | 尚未定位，也未量化 |
| DEV-5 | "余弦与幅度无关，方向结论不受幅度影响" | 余弦只消除直接的尺度影响 | 方向噪声、样本筛选、任务混杂仍可能随幅度变化 |
| DEV-1 | "两个分支的舍入互不相关" | 删去，改为"数值因素的贡献尚未分离" | 该假设未经验证 |
