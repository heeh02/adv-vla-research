## 偏离

### DEV-P4-1（实现错误修复，2026-10-09，读取 v1 结果时发现）
- **现象**：analysis v1 的第三部分里，"同一观测"核验（QC-S：三个种子的 `visual_token_rms` 相同）被错误地应用到所有锚点类。lm1、lm2 和后期锚点的已访问状态按设计本来就各不相同，因此全部被排除，没有输出结果。
- **对照预注册**：§5 规定 QC-S 只用于 q0；后期锚点只需"单独报告，不称作同状态复现"。
- **处理**：在 analysis v2 中只对 q0 施加 QC-S；后期锚点只要求三个种子齐全、噪声互不相同。
  - q0 的结果不受影响。v1 和 v2 的 q0 结果应当相同，作为一致性检查报告。
  - v1 的代码原样保留为 `p4/control/bundles/analyze-v1-as-run.py`，结果保留在 `p4/results/analysis/`。

### PH-1（事后检查，非预注册，只作为对阴性结论的稳健性检查）
- **动机**：预注册的主对比是 M3 对 M2L，但 v1 显示最强基线是不拟合的保持外推 M2 = 9·u₀，而 M2L 低于 M2。于是自然的疑问是：读出方向也许能在最强基线之上提供增量，只是 M2L 这个底座偏弱，把它掩盖了。
- **做法**：只做一项检查，不换特征。M2R = 9·u₀ + 岭回归[PCA_m(n₀)]，拟合残差 Y − 9·u₀；网格、内层 CV、外层折与 M3 完全相同；同时做扰动族留出。
- **解释规则**：沿用 §4 的数值门槛（≥ 0.02 且区间下界 > 0）。即使达到门槛，也只能作为事后线索，不能改写预注册的判定。

### PH-2（事后检查，非预注册：跨种子"拟合后的命令平均"对照）
- **动机**：analysis v2 显示，在后期锚点（各种子访问的状态不同）上，读出模型 C2、C3 超过了直接命令平均 C1：lm2 为 +0.20，later 为 +0.20。
  - 但 C1 不拟合、不收缩，而 C2、C3 带有条件均值底座和岭收缩。
  - 状态不同时，原样平均的命令差容易方差大、标定差。仅仅"收缩"本身就可能提高 EEF。
  - 因此，这个优势有可能来自标定，而不是来自读出方向的信息。
- **做法**：只增加一个对照。C1s = M0_cond + 岭回归[z(C1)]，λ 网格与 M2L 相同（24 个值），内外层 CV 与 C2、C3 相同。然后报告 C2 − C1s 与 C3 − C1s。
- **解释规则**：只有在 C1s 之上仍满足 ≥ 0.02 且区间下界 > 0，才称"读出方向在后期锚点提供了标定之外的信息"。这仍然属于事后结论。预注册对 C1 的判定照原样报告。

### PH-3（事后描述性检查，非预注册：同状态反事实下的可读比例）
- **动机**：第一部分表明，有效增益下降几乎全部来自可读比例 ρ 的下降：Δr 的能量在头的零空间里增长约 19 倍，而 clean 读出本身只下降 1.6 倍。剩下一个可以区分的竞争解释：
  - 零空间增长来自两条分支的 x_t 轨迹逐步分离（状态差异累积）；
  - 还是来自时间条件网络在后期 τ 上对同一视觉差异的表达方式。
- **数据**：trace 中已有共享状态反事实 `shared_xt/readout_delta` 与 `shared_xt/velocity_delta`，在 τ 索引 0、5、9 上，两分支都处在 clean 的 x_t。它们来自影子重放，属于反事实，与原生记录分开标注。
- **做法**：只在云端计算逐 trace 标量（R、A、L、V 及 ρ），回传标量表；与同一 τ 上自由路径的 ρ 比较。只做描述，不设判据，不再追加其他特征。
