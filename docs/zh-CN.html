视觉—语言—动作策略中的共享视觉响应与任务结果

机器人策略可能对视觉变化反应强烈，却依然完成任务；也可能几乎没有反应，却以失败告终。我们沿着特征、指令、运动和任务结果，追踪视觉扰动在两个冻结策略中的传递，并测量反应与失效在何处分离。

研究问题

从像素到任务结果，追踪一次扰动

相机位置移动、图像噪声等视觉变化并不改变任务本身，却可能显著降低视觉—语言—动作策略的成功率。要让这些策略更稳健，就需要知道扰动改变了策略内部的什么，以及如何评价一种修正。我们在路径的每个环节，比较从同一物理状态、相同策略噪声开始的一次无扰动运行和一次扰动运行。

  1. 图像无扰动或扰动后的观测
  2. 特征动作专家第 L1、L9、L18 层的状态
  3. 指令发送给机器人的前五条指令
  4. 运动第 5 和第 60 个控制步后的末端执行器位置
  5. 结果回合结束时任务是否成功
  1. 从图像到特征。不同扰动是否让特征沿共享方向变化？
  2. 从特征到指令。沿这些方向恢复无扰动数值，能否让指令回到接近无扰动运行的位置？
  3. 从指令到运动和结果。指令变化与运动、任务成功之间有什么关系？
敏感性
扰动使特征、指令或运动改变了多少。
脆弱性
扰动使任务成功率付出了多少代价。

图像 → 特征

不同扰动让特征沿相同的少数方向变化

在 π0.5 中，我们在每一层用扰动引起的特征变化拟合 16 个方向。每次拟合同时留出待测试的任务和扰动族，因此，用 Camera 响应测试的方向从未见过 Camera 响应。

面对这些未见过的响应，16 个方向仍能捕获大部分变化；而用无扰动特征拟合的 16 个方向或随机选取的方向几乎捕获不到。该结果在 π0 中、使用其他方向数量时，以及在回合中较晚的观测上同样成立。

特征 → 指令

沿这些方向恢复无扰动数值，可以把指令拉回

作为一项因果检验，我们在动作生成过程中，使用同一状态的无扰动观测，在中间层 L9 沿共享方向把无扰动数值复制回去。其他所有内容都保持扰动状态，包括后续块仍然读取的图像。

在 31 个留出任务上，前五条指令向无扰动运行的指令靠近。27 个 Camera 任务中有 25 个、30 个 Sensor Noise 任务中有 24 个误差下降。1,024 个通道中的 16 个方向，达到了替换整个层所能实现效果的 86.9% 和 70.7%。任务成功率也分别提高 1.85 和 3.33 个百分点。

该测试需要同一状态的无扰动观测，因此它是一项受控实验，而不是一种可以直接部署的方法。

指令 → 运动 → 结果

变化有多大，不等于代价有多大

指令变化确实会传递到机器人。五个控制步后，指令变化的大小几乎能完美排出运动变化的大小（π0.5 的秩相关为 0.95，π0 为 0.97）；到第 60 个控制步，这种联系仍然可见（0.47 和 0.41）。

但一次运行移动了多远，并不能说明它是否会失败。按运动变化对运行排序时，混合所有扰动族得到的 AUROC 为 0.72 和 0.64，限定在同一扰动族内为 0.62 和 0.55，而 π0 在 Sensor Noise 下仅为 0.49。AUROC 为 0.5 相当于随机判断。

净成功率会掩盖成功的丢失与新增

扰动后，一些原本成功的运行会失败，一些原本失败的运行会成功，净变化只显示两者之差。在 Background 下，π0.5 丢失 3.57% 的成功，也新增 3.57% 的成功：净成功率不变，但实际有 7.14% 的结果发生改变。

仅是一次无扰动重跑，也能改变多达 7.1% 的结果，因此必须参照无扰动重跑来解读这些变化。在两个策略中，Camera 和 Sensor Noise 下丢失的成功都超过重跑水平，新增的成功则没有。

其他比较中的同一落差

移除一个前灯对 π0.5 前五条指令的改变，是图像统计量相匹配的调暗操作的 5.1 倍，但两者都在 80 次运行中成功 77 次。在一项包含十个条件的研究中，条件的平均指令变化可以排出平均成功率变化（秩相关为 −0.90）；但看全部 400 个任务与条件组合时，相关性仅为 −0.075。

对后续研究的启示

一个干预位置，一把评估标尺

共同的干预位置

不同种类的扰动会沿策略内部相同的少数方向产生作用，而恢复这些方向会改变指令。不同干扰都可以通过同一组内部成分来研究和修正。

评估标尺

任何修正，包括我们的修正，都应该以无扰动重跑为参照，用配对任务结果来评价：哪些成功被丢失，哪些成功被新增，以及这与策略自身随机性造成的结果有何不同。

实验设置

三项配对研究，约 4,000 次模拟器运行

所有研究都在 LIBERO 模拟器中，使用经过 LIBERO 微调后冻结的 π0.5 和 π0，并测试 LIBERO-Plus 的四类扰动：Background、Camera、Light 和 Sensor Noise。每项比较都让同一设定从相同初始状态、相同策略噪声开始，分别进行一次无扰动运行和一次扰动运行，因此只有图像不同。

局限

  • 敏感性在回合开始时测量；后续与接触相关的关键步骤留待未来研究。
  • 恢复实验只在 π0.5 的一层、16 个方向、四类扰动中的两类和 216 个案例上测试，并且需要同一状态的无扰动观测。
  • 共享方向也承载 Background 引起的响应，而这种扰动对 π0.5 的净成功率没有影响。它们描述策略如何响应视觉变化，无论这种变化有害与否。
  • 所有实验均为模拟实验，使用两个相关策略，并选用扰动程度适中的设定。

复现

一条命令核对主要数值

检查只需 Python 3.9 或更高版本，以及 Python 标准库。它会重建共享方向结果背后的任务分数，重新计算 216 个恢复案例的指令误差，并重新计算配对结果。仓库还提供绘图脚本、采集代码和数据发布。

git clone https://github.com/heeh02/adv-vla-research.git
cd adv-vla-research
