# 第三篇现有证据结项裁决

**裁决：停止追加实验、训练和可选云CPU分析，以已有证据收尾。当前材料不宜作为一篇有充分独立贡献的RSS论文继续投入。**

研究问题是同一T20父模型和数据支持下，额外10000次更新及floor/reheat安排是否产生可重复闭环收益。四端点确已训练到30k；D7训练probe改善，但共同留出仅存D32标量，不能据此认定D7泛化变差。

固定1053 Plus面板的全部已有结果已接通：1154个T30及3022个基线端点。原配对门下，floor两seed为16增益/12损害（255对）和12/13（258对），reheat为6/5（174对）和8/10（205对）。直接reheat-floor为12/11（238对）和12/15（265对）。各行支持不同，不能合并成总体成功率；没有跨seed一致的正收益。当前mapped-task合格权重只有16.15%–24.58%，因此也不能证明总体零效应或等效。

q0身份拒配不能直接解释为大幅物理偏移。两个固定原始输入见证显示状态差异约1e−16至1e−15，其中一例观测和噪声相同，另一例少量像素最多差一个uint8等级。两例不代表全部拒配，未改变原门。此诊断完善了证据边界，没有建立独立的新机制。

继续投入的预期收益不足：更多同类轨迹主要增加覆盖与精度，当前没有可重复的正效应，也没有可据此提出的明确训练改进机制。为了使第三篇达到更强贡献而扩模型、任务或方法，会开启新的研究，不属于本次收尾。阴性/混合观察值得保留，但不应仅因已有资源投入而继续投入。

最终可保留结论：**在本次固定支持、两种续训安排和当前合格评价支持上，更充分拟合没有转化成已证实的、跨seed稳定的闭环收益。** 不泛化为“继续训练无用”，不把未观察数据算失败，不称总体等效。
