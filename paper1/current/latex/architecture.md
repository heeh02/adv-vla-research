## 1. 全文核心问题

视觉扰动如何影响 VLA 的内部计算与动作生成，以及这些变化对应怎样的机器人运动和任务结果。

同一任务中的视觉变化会改变动作输出和任务表现，但动作变化的大小与成功损失并不直接对应。受控视觉扰动同时是研究对象和实验手段：保持任务不变，检查内部响应、干预这些响应，并追踪机器人执行。

两个正文结果章节建立三项联系：共享响应跨条件复用；恢复共享成分能够修正初始动作指令；指令变化与早期运动紧密关联，但运动幅度与任务结果需要分别检验。补充注意力分析展示互补的内部计算现象。

## 3. 第四章：共享响应与动作效应

沿用当前共享结构、读出与恢复的实验叙事；本次迁移不改变第四章的科学结论。

### 4.1 共享响应跨任务与扰动类别复用

问题：不同任务、不同视觉扰动引起的内部变化，是否具有共同结构？

写作顺序：共同方向的直观含义 → PCA 与任务/扰动类别联合留出 → 同维度 clean/random 对照 → 重建公式与能量定义 → 最强结果 → 简要扩展证据。

核心证据：404 个匹配样本中，16 个共享通道方向保留 36.5–83.6% 的中心化响应能量，超过 clean 的 0.5–10.2% 和 random 的 1.3–1.9%。每个计划位置各有 16 个观测坐标，十个位置共 160 个系数。重建使用已观察到的测试响应，不写成预测未观察的响应。

补充中的均值、秩、聚合方式、完整样本、第二策略与跨观察分析承担排除简单替代解释及检查复用范围的职责。独立跨观察实验的视觉条件在拟合时已见，不混同联合任务/类别留出。

落点：找到可以跨任务分析和干预的共同内部成分。随后追问这些成分与动作变化有什么联系。

### 4.2 重建响应与预测动作指令偏移选择不同的层

采用同一 404 个样本与留出方式，用固定 affine ridge 读出预测最初五个平移指令的差异。将预测误差与“预测没有指令变化”的基线比较，先解释图中 1 的含义。

主发现：在 L1、L9、L18 三个被测层中，L1 保留的响应能量比例最高，L18 的固定线性读出误差最低。补入 G1 同任务证据：Background、Camera、Light、Sensor 分别有 24/28、26/28、27/28、27/28 个任务同时呈现这两项排序。四类重复使用同一组 28 个任务，不能加总为独立任务。

L18 的 response 与 clean 读出均优于无变化基线；二者的差异区间包括零。浅层与中层的相对基底优势、绝对基线表现应保持可区分。首步流输出、非线性及完整隐藏状态对照放在补充，正文简洁交代读出器与层的适用范围。

落点：为描述内部响应和预测动作选择网络层时，应分别检验这两个目标。随后从离线预测进入原生生成中的实际干预。

### 4.3 恢复共享响应成分修正动作指令

问题：直接恢复这些成分，能否使策略自身生成的动作指令靠近无扰动参考？

先解释实验，再给公式：在每次规划、每个生成步，渲染当前物理状态的无扰动观测；在相同生成状态和时间比较 L9 特征；仅将共享方向上的坐标换为无扰动值，其余分量及后续视觉条件保持扰动状态。无扰动参考是干预所使用的实验信息。

保留九个开发任务、31 个独立确认任务、联合留出、主任务终点及预设指令终点。对照为未编辑、clean/random 基底与 full-H 恢复。自然投影的方向和实际修改幅度共同变化，比较的是完整恢复规则；共同目标幅度的开发集结果留在补充。

最硬结果：五个实际发出的平移指令拼接后的距离，Camera 从 0.409 降到 0.312，Sensor 从 0.209 降到 0.199；与未编辑、clean 和 random 的六项指令比较同时区间均为正。full-H 的 0.297/0.194 是同实验参照，不称理论最优上限。

正面呈现实测成功率：Camera 73.15%→75.00%，Sensor 83.33%→86.67%；对应无扰动基线 98.15%/97.50%。增益 +1.85 [−8.33,11.11] 与 +3.33 [−1.67,9.17] 个百分点，为六项成功率比较的同时 95% 区间。保留数据和区间，不写成无效，也不将点估计写成已证明的普遍成功率收益。

落点：无需重新训练，恢复共享成分能够修正策略自身的动作输出，为进一步研究内部修正提供具体实验依据。

## 4. 补充S20：注意力与特征响应

### S20.1 一个视角的变化影响其他输入的深层特征

保持机器人状态、腕部图像和任务文本不变，仅改变主相机视角，先呈现未改变输入的深层特征发生变化这一发现。再解释区域内部的注意力重新分配与该区域获得的总注意力是不同量，用层排序反转支持这一说明。

### S20.2 注意力权重与输出特征呈现不同变化趋势

先说明权重决定如何组合特征，再介绍 P、W、H 的测量位置。重点呈现动作生成中 P 差异缩小、W 差异扩大。块后 H 的绝对与相对差异进一步说明比较尺度的作用。

P/W 来自诊断重放，H 来自原生执行；各分支自身生成状态的差异包含在比较中。这些测量身份集中解释，不反复铺设限制段。不把趋势当成门控机制或某次任务失败的已验证原因。

### 5.1 从动作指令到早晚运动
