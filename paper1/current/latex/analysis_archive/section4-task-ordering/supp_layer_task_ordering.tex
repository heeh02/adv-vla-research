\paragraph{The best layers differ within most tasks.}
We compare response retention and fixed affine translation-prediction MSE at L1, L9 and L18 within each task, using the same paired cases. In the table below, \emph{best-layer separation} counts tasks for which L1 has strictly higher retained response energy than both other layers and L18 has strictly lower prediction MSE than both. This separation holds in 24--27 of the 28 tasks in each visual family. The \emph{full ordering} column additionally requires both retention and prediction MSE to decrease strictly from L1 through L9 to L18. It therefore also checks the position of L9. The same 28 tasks appear in all four families. These descriptive counts summarize the saved task-level results and are reported without an additional inferential test.
