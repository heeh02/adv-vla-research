\section{Conclusion}

Sensitivity is not fragility: across two VLA policies and four visual perturbation families, how strongly a policy responds to a perturbation early in an episode is a poor guide to how much task success it loses. Inside $\pi_{0.5}$, different perturbations change features along 16 shared directions per layer, and copying clean values back along them reduces command error. In paired executions, a perturbation can move the robot less than a clean rerun and still cost success, motion size is a poor predictor of which runs fail, and net success hides changes in both directions. These results give later work a foundation: a common internal target, the shared directions, and a yardstick, paired outcomes against clean reruns, by which to judge any correction, ours included.
