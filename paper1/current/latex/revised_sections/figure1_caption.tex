\textbf{Where a perturbation's effect is recorded and restored in frozen $\pi_{0.5}$.}
(a) A clean and a perturbed observation of the same physical state (main camera shown) pass through the policy with the same policy noise. Each block of the action expert attends to the image and instruction tokens (K/V) while it turns noisy actions into commands. After action-expert blocks L1, L9, and L18 we record the response, the perturbed-minus-clean feature difference $\Delta H_\ell = H^{p}_\ell - H^{c}_\ell$, and fit 16 shared directions per layer (Fig.~\ref{fig:token-structure}). Restoration copies the clean values along these directions back after L9.
(b) Restoration compared with the unedited perturbed run (means, simultaneous 95\% intervals; Table~\ref{tab:restoration}). The error of the first five commands falls by 0.0972 (24\%) under Camera and 0.0105 (5\%) under Sensor Noise; observed task success is higher by 1.85 (Camera) and 3.33 (Sensor Noise) percentage points, with intervals that include zero.
