\paragraph{Wrist-camera values respond at L9 and L18 but not at L1.}
The Camera and Sensor Noise subsets contain 102 and 110 recorded pairs, each on the same 28 tasks. At the first query, we measure the norm of the wrist-value difference relative to the clean wrist-value norm. These prefix values are recomputed once per query, so they have no generation-step axis. Means use task-equal weighting over two policy-noise draws per setting. Brackets are pointwise 95\% intervals from 2,000 whole-task bootstrap draws (descriptive, not simultaneous across rows).
