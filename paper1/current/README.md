# Sensitivity Is Not Fragility

[Read the paper](latex/main.pdf) · [Read the supplement](latex/supplement.pdf) · [Reproduce the results](../../reproduce/README.md)

The current manuscript is the November 13 revision. For Figures 1b, 3, 4 and 5, run `python3 -B reproduce/paper.py` from the repository root. The command uses the retained data included in the checkout. Figure 4 uses task errors and intervention outcomes, and Figure 5 uses the five-arm case records. The figure-to-evidence guide identifies inputs, estimators, confidence intervals and support for each comparison.

The source for both PDFs is in [latex](latex). The figure scripts and their data are in [figure_src](figure_src). To inspect the implementation of the original studies, see [collection and statistical code](../reproduction). [Historical editorial notes in Chinese](REVISION-HISTORY.zh.md).
