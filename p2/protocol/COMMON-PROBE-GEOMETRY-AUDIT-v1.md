# 共同可表示人工 probe：先审问题，再审失真

2026-10-19；第二篇负责人。冻结于真实候选几何读出之前。用户要求继续推进第二篇，判断共同可表示人工 probe 是否值得做，先明确能区分和会损失的内容。此执行范围是既有数据云 CPU 分析；不包含 GPU、新模型、环境或训练调用。

## 本次价值判断与唯一问题

人工 probe 值得做一次有界几何审查，因为自然剂量的严格不可表示性已实证，而当前只有失败坐标数，没有其能量、方向和位置损失。它不值得仅凭“多数坐标可表示”直接进入 GPU。先回答：在两个已有合法计算背景中，保持同符号且不放大自然每坐标剂量时，最近的共同可表示增量改变了什么？

固定支持仍为 T06-PC/q11、j6、L9/index8，A=none、B=pulse，d=已有 persistent−pulse 的实际 native W 差。已见开发锚点，不扩人口、不换层/flow、不选效应大的案例。原完整 10×1024 坐标保留；不从 action、v、成功率、未来状态选择规则。

## 必须先明确的因果对象

令 F_s(c) 表示在合法历史 s 的完整计算背景中，仅在指定 L9/j6 post-WO/pre-gate 节点施加实际增量 c 后的输出。目标是比较 D_s(c)=F_s(c)−F_s(0)，以及 I(c)=D_B(c)−D_A(c)。每个状态都减自身 baseline；A/B 差不是处理效应。

合格的非零 I(c) 可排除“这两个背景中，对这一个相同节点增量的响应完全相同”。它控制了施加增量的全 signed 结构和位置，超出仅等范数对照。它不能单独说明差异源自哪一类接收变量，更不能说明原 same-E 的差异有多少由读取或接收贡献。

尤其 baseline W 也不同。即使共同下游函数完全相同，例如 F(W)=W²，相同 c 在不同 W 上也会产生不同增量。因此“same-W 有差异”本身不是新的高层补偿机制；BF16 gate 乘法/残差加法的舍入、norm/MLP 非线性及后续 attention 都是竞争解释。同 τ 的 gate 已证相同且来自 time conditioning，不称为物理状态门控。

I(c)=0 只约束这个 probe、两个背景、此剂量和读出；不能推出读取侧足够，也不能排除其他自然方向的接收差异。**本条撤回并覆盖旧 SAME-W-DECISION-RULE-v1.md 第6节末段中“same-E不同而same-W无差异则读取足够”的过强推断；旧文件保留历史。**

首步 v 与剩余生成动作必须分开。前者仍包括目标节点后当前调用的全部计算；后者还含后续 flow 状态、读取和动力学。它们都不是 issued、真实运动或任务成功率。

## 唯一人工规则

以精确 BF16 位模式对应的 dyadic 整数计算。对每坐标 i，定义 C_i={c : A_i+c、B_i+c 均为 finite BF16}。约束 c 与 d_i 同号或为0，且 |c|≤|d_i|。选 c_i 为约束集合中离 d_i 最近者，即同向最大可达幅度。d_i=0 时选0。

此标量选择数值唯一，自动保留所有原本共同可表示的自然增量；不把623个失败点直接删掉，不放大、不翻向、不新增原零坐标。零在集合内确保算法有解，但全零不能称为有辨别力。signed zero 的数值差与位模式分开；不产生供模型消费的 target 文件。

按此约束，逐坐标最小平方误差也最小化完整欧氏误差；**这只是坐标空间的受限最优，不能推成最小动作失真、语义最优或自然流形内。** 原生通道坐标有特权；规则不可宣称旋转不变。两状态共同格点依赖 A/B，因此将来的跨pair probe通常不同，不能汇总成同一固定外生方向。

零掉原失败坐标只作为几何损失参照，不是第二个待选模型干预。不得比较多个规则后挑作用最强者；不补 norm renormalization、正负剂量或阈值扫描。

## 读出与解释

全部完整支持及10个位置分别保存：参考与候选能量、误差能量、signed inner product、范数比、cosine（零能量保 undefined）、保持/收缩/归零/符号变化计数，原失败坐标参考能量份额，以及零掉失败点的损失参照。保 signed 向量和的抵消诊断；通道求和只作基底相关诊断，不当作动作贡献。

关键损失是自然剂量身份、方向/位置权重和潜在抵消关系，绝不只报失败坐标比例。全局 cosine 很高也不保证关键位置或某个高增益方向保真。对 r=d−c，有 F_s(d)−F_s(c) 的大小需要下游平滑/增益界或实际桥接；当前没有该界，几何接近不构成功能接近。

此 CPU 审查不设置从结果反调的科学通过阈值，也不自动发 GPU GO。所有几何数值公开后，由明确因果价值和剩余技术成本做审慎选择；若提出新的阈值，须标为新的后续设计，不能回称本数据盲通过。
